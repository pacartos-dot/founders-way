# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, criticize ideas and not people, and no harassment, hate speech or spam.

The maintainer may edit or delete comments, close issues and PRs, and block users who break these rules. Report problems privately with GitHub's **Report content** option (the ⋯ menu on any comment), or by opening a private security advisory if it involves the code.
